- Change summary: publish the reviewed move to rigorloop-records-v2 and targeted recording, retire legacy lifecycle commands and record formats, unify Design authoring, and deliver the approved shared-model and release coordination changes.
- Rationale: changes since v0.5.0 remove supported commands, skills and runtime record-format support. Release REL-SR-01/02 requires a major version for breaking public contracts; 0.5.1 was an unpublished candidate and is not the selected release.
- Dist-tag decision: latest after successful trusted publication.
