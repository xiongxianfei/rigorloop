## Filled proposal specimen

```md
# Offline task export

## Challenge

Users cannot retain a readable copy of their own task list when disconnected.

## Goals

Allow a user to save a readable copy of the current task list for offline use.

## Scope and non-goals

Include export of the user's current list. Exclude importing, account synchronization and background delivery.

## Governing principle

Users control when their information leaves the application.

## Proposed direction

Provide an explicit export action that creates a readable local document of the current list.

## Feasibility

Feasible under the bounded assumption that the application can read the current user's list and write a user-selected local document. Design must establish the supported format and failure behavior. No additional service is selected.

## Decision requested

Approve this export direction for Design. This does not approve implementation, publication or a synchronization feature.
```
