# Workflow cancellation: custom activation publication initiative

Decision date: 2026-08-06

The owner cancelled this workflow after M2 code-review R11.
The custom candidate-validation and atomic-publication mechanism consumed disproportionate implementation and review effort for a thin project while delaying the user-visible activation release.

The initiative's artifacts and review findings remain historical evidence.
Open findings are not waived and the custom publisher is not approved for publication.
The replacement direction is owned by `docs/changes/2026-08-06-usability-first-boundary-release/change.yaml` and `docs/proposals/2026-08-06-usability-first-boundary-release.md`.

No tag, remote ref, GitHub release, or npm package was created or mutated by this cancellation.
