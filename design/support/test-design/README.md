# Test design

The [system test design](system-test-design.md) owns system scenarios, conditions and independently expected outcomes. Module contracts retain required behavior. Test implementation changes alone do not require design edits.

[Shared rules](rules.md) explain selection, assertions, fixtures and maintenance. [Validation](../validation.md#current-coverage-allocation) owns current executable mappings, commands and coverage gaps; Change records own actual results and judgments. Keep one system design, without separate model catalogs.
