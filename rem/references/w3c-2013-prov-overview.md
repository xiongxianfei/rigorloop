# W3C PROV Overview

## Key takeaway

Knowing where information came from helps assess it; provenance is not a correctness certificate.

## Summary

The PROV overview organizes provenance around entities, activities and agents. REM uses that distinction to explain how an observation, analysis or view can retain its origin without treating the origin as proof of satisfaction.
