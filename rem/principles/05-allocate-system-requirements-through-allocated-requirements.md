# Principle 5: Allocate System Requirements through Allocated Requirements

## Relationship and why

Assigning work to a Module identifies responsibility, but a responsibility assignment alone does not state what that Module must satisfy. An allocated obligation connects the system requirement to a specific architectural context while retaining requirement meaning, so the allocation can be reviewed for both accountability and conformance.

## REM commitment

An AR remains a requirement while assigning a lower-level obligation to architecture.

## Application

The [Requirement model](../models/requirements.md) owns AR derivation and parentage; [architecture allocation](../models/architecture-allocation.md) owns the accountable Module relationship.
