# REM Practices

Practices combine the canonical Concepts, Principles, Models and Methods to accomplish an engineering goal.
They guide selection and iteration without redefining model rules or prescribing project workflow stages.

| Goal | Practice |
| --- | --- |
| Take a need through requirements, design, realization and assessment | [Engineer a change](engineer-change/README.md) |
| Assess an existing implementation and locate missing correspondence | [Review an existing system](review-existing-system.md) |
| Plan and interpret conformance and intended-use assessments together | [Verify and validate an engineering slice](verify-and-validate-slice.md) |
| Understand why REM's knowledge owners and relationships exist | [Understand REM](understand-rem/README.md) |

The [worked example](engineer-change/WORKED-EXAMPLE.md) illustrates a bounded application with explicit planned evidence.
Example identities are local to that illustration; they are not RigorLoop project records or new method rules.
