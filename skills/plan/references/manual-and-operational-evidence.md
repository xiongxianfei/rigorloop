# Manual and operational evidence

Use this method when an important outcome cannot be demonstrated adequately through deterministic automated checks.

State the observable condition, operator or reviewer, environment assumptions, exact bounded action, expected result, evidence form, and expiry or freshness rule. Prefer repeatable commands and captured outputs; use a concise manual note only where automation would be unsafe, misleading, or unavailable.

Manual evidence does not relax requirement ownership, review independence, or the need to explain why automated proof is insufficient.
