# Option discovery methods

Load this method only when the core sequence does not yet expose materially distinct directions.

## Reframe the problem

Restate the desired outcome without the requested solution. Identify who experiences the problem, what changes for them, which behavior must remain unchanged, and which constraint is real versus assumed. If two plausible framings imply different option sets, record both rather than silently selecting one.

## Generate distinct directions

Vary the mechanism, scope, ownership boundary, adoption path, and reversibility. Consider a credible status quo or defer direction, a minimal intervention, and a broader intervention only when each represents a real choice. Merge variants that share the same material trade-offs; do not count implementation details as separate directions.

## Challenge each direction

For each option, ask what would make it unsuitable, which assumption it depends on, who bears its cost, which failure is hardest to reverse, and which evidence could change its relative position. Stop when another option would repeat an existing direction without adding a material trade-off.

## Choose comparison criteria

Use criteria that can change the owner's decision, such as user value, scope, reversibility, operational burden, compatibility, time sensitivity, or evidence confidence. Avoid detailed implementation estimates when architecture and delivery have not yet been settled.
